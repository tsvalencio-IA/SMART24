Obrigado.

thIAguinho Soluções — tecnologia sob medida.

## English

Subject: Android P2P SDK/API request for authorized Yoosee shared-camera integration

Hello,

We are thIAguinho Soluções and we are developing SMART24, an authorized monitoring platform for self-service retail locations.

Our Android application needs to operate as an authorized Yoosee account: the camera owner shares a camera with a dedicated SMART24 account, then our application authenticates that account, lists shared cameras and opens the remote live video.

We need:

- current Android SDK for Yoosee/Gwell/IoTVideo;
- AppId and AppToken for package `br.com.thiaguinhosolucoes.smart24vision`;
- AppVersion requirements;
- e-mail/password login example;
- API to list devices shared with the logged-in account;
- online-status API;
- remote P2P live-view API;
- callback/API for raw video frames or encoded stream access for computer-vision processing;
- shared/guest account permission documentation;
- Android 14/15 and arm64-v8a compatibility;
- commercial SDK licensing terms.

The SMART24 account does not need to become the device owner. Access will be explicitly granted by the owner using Yoosee device sharing.

Thank you.
