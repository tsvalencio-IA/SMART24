# Identidade do APK SMART24

O arquivo `smart24-app-icon-1024.png` é a matriz oficial do ícone Android S24 desta versão.

As pastas `mipmap-*` contêm as variações normal, circular e adaptativa geradas para as densidades Android. O manifesto referencia `@mipmap/ic_launcher` e `@mipmap/ic_launcher_round`.

Paleta aplicada:

- azul-marinho: `#07111F` / `#000C24`;
- verde tecnológico: `#00D79A`;
- branco: `#FFFFFF`.
