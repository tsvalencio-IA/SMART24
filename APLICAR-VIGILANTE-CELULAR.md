# Aplicar no repositório

Copie o conteúdo deste pacote por cima da raiz do repositório SMART24 e faça commit.

Depois:

1. GitHub -> Actions.
2. Execute `Build SMART24 Vigilante Celular APK`.
3. Baixe o artefato `SMART24-Vigilante-Celular-APK`.
4. Instale `app-debug.apk` no Android.

A primeira tela do APK já será o SMART24 Vigilante, não o fluxo Yoosee.
